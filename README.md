# Prince Pharma – Krishna Prasad

Responsive static website for Prince Pharma, a local medical store in Vishwambharpur, Garkha, Saran, Bihar.

## Files
- `index.html` — main store website and SEO metadata
- `about.html` — separate profile/contact page for Krishna Prasad
- `style.css` — responsive design
- `script.js` — mobile navigation and back-to-top button
- Image assets — existing store and owner images from the supplied project
- Google verification HTML files — retained from the original upload

## Publish
Upload the contents of this folder to the root of your GitHub Pages repository (not the enclosing ZIP folder). Keep image filenames unchanged. Then open the published homepage and `about.html` to test.

## Search visibility checklist
1. In Google Search Console, inspect the exact published homepage URL and click **Request indexing** after publishing.
2. Submit a sitemap only after creating one with the exact live site URL. Do not submit a guessed URL.
3. Keep the store name, phone and address consistent with the Google Business Profile, if the owner has one.
4. Add the final published website URL to the Google Business Profile and other legitimate business listings.
5. Search results and titles are chosen by Google; this website improves clarity and structured data but cannot guarantee a ranking or immediate display.
